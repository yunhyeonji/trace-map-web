# TraceMap — 기획서

> 다녀온 여행을 지도 위에 쌓아가는 개인 여행 기록장.
> 로그인 없이 기기에 저장하거나, 계정으로 여러 기기에서 동기화할 수 있다.

## 1. 한 줄 정의

**"여행이 끝난 뒤, 사진과 동선과 이야기를 한 장의 기록으로 남기는 곳."**

일정을 짜는 플래너가 아니라 *다녀온 여행*을 보관하는 아카이브다. 기록이 쌓일수록
세계 지도가 채워지는 경험을 핵심 보상으로 둔다.

## 2. 타깃 & 문제

| 누구                            | 지금의 불편                                                     | TraceMap이 주는 것                                    |
| ------------------------------- | --------------------------------------------------------------- | ----------------------------------------------------- |
| 1년에 2~5번 여행하는 20~30대    | 사진은 갤러리에, 동선은 지도 앱에, 감상은 메모 앱에 흩어져 있다 | 여행 한 번 = 기록 한 장. 사진·동선·이야기가 한 화면에 |
| SNS에 올리긴 부담스러운 사람    | 공개 피드가 아니면 남길 곳이 없다                               | 공개 없는 개인 기록. 로그인은 선택                          |
| "몇 개국 가봤지?"가 궁금한 사람 | 직접 세어야 한다                                                | 방문 국가·여행 일수·도시 수 자동 집계 + 세계 지도     |

## 3. 범위 (MVP)

**한다**

- 여행 기록 작성 / 수정 / 삭제
- 사진 첨부 (최대 20장, 대표 사진 지정, 자동 리사이즈)
- 장소 검색(OpenStreetMap) → 지도에 핀 + 방문 순서대로 동선 표시
- 목록: 연도별 타임라인, 검색, 국가 필터
- 홈: 방문 국가 세계 지도 + 누적 통계 + 최근 기록
- 백업: JSON 내보내기 / 가져오기, 전체 삭제
- 선택적 로그인(Google·카카오·이메일) 및 기기 간 동기화
- 로그인 전 로컬 기록을 계정으로 이전
- 샘플 데이터로 둘러보기 (포트폴리오 데모용)
- 라이트 / 다크 모드, 모바일 우선 반응형

**하지 않는다 (의도적으로)**

- 공유 링크, 소셜 기능
- 여행 계획/예산/체크리스트

## 4. 정보 구조

```
/                 홈 — 내 여행 지도 (통계 · 세계 지도 · 최근 기록)
/trips            기록 — 연도별 타임라인, 검색, 국가 필터
/trips/new        새 기록 작성
/trips/[id]       기록 상세 — 커버, 이야기, 사진, 동선 지도
/trips/[id]/edit  기록 수정
/settings         데이터 관리 — 백업 / 복원 / 초기화
/login            선택적 계정 로그인
```

내비게이션: 데스크톱은 상단 헤더, 모바일은 하단 탭바(홈 · 기록 · ＋ · 설정).
"새 기록"은 모든 화면에서 한 번에 닿는 위치에 둔다.

## 5. 핵심 플로우

1. **첫 방문** → 빈 지도 + "첫 여행 기록하기" / "샘플로 둘러보기" 두 가지 선택지
2. **기록 작성** → 기본 정보(제목·나라·날짜) → 다녀온 곳 → 사진 → 이야기 → 저장
   - 필수는 제목·나라·시작일 세 개뿐. 나머지는 나중에 채워도 된다
   - 첫 장소를 추가하면 나라가 비어 있을 때 자동으로 채운다
3. **저장 후** → 상세 화면으로 이동해 완성된 기록을 바로 보여준다
4. **다시 보기** → 홈 지도에서 나라를 누르면 그 나라 기록만 모아 보인다

## 6. 데이터 모델

```ts
Trip {
  id, title, countryCode, city?,
  startDate, endDate?,           // YYYY-MM-DD
  places: Place[],               // 방문 순서대로
  photoIds: string[], coverPhotoId?,
  story, companions[], tags[],
  createdAt, updatedAt
}
Place { id, name, address, lat, lng, memo? }
Photo { id, blob, width, height }  // 별도 스토어
```

- 로그아웃 저장소: **IndexedDB** (`trips`, `photos` 두 스토어)
- 로그인 저장소: **Supabase** Postgres(기록) + Storage(사진), RLS로 본인 데이터만 접근
- 사진은 업로드 시 긴 변 1600px JPEG로 줄여 저장 용량을 아낀다
- 백업 JSON에는 사진을 base64로 포함한다

## 7. 디자인 원칙

- **숲 같은 차분함** — 차가운 대시보드 대신 Earthy Forest 팔레트. Dust Grey 배경에 Hunter Green 포인트, Fern 강조 (다크 모드는 Dry Sage 포인트)
- **콘텐츠 위에 떠 있는 내비게이션** — 헤더와 모바일 탭바는 반투명 글래스. 탭바는 화면 아래에 떠 있는 캡슐 형태
- **Apple HIG를 따른다** — 시스템 서체(SF Pro + Apple SD Gothic Neo), HIG 타입 스케일(Large Title 34 ~ Caption 12), 설정 앱 같은 그룹 목록, iOS 시트형 작성 화면(취소 · 제목 · 추가)
- **장식보다 내용** — 반짝이 배지, 색칠한 강조 단어, 번호 동그라미, 점선 상자를 쓰지 않는다. 사진 위에는 탐색 버튼만 둔다
- **문구는 짧고 담백하게** — "~합니다" 체. 버튼은 동사 하나("추가", "완료", "삭제"), 안내는 그룹 아래 회색 꼬리말로
- **필수 항목은 버튼으로 알린다** — 별표 대신 제목·나라·기간이 채워져야 "추가"가 켜진다
- **사진이 주인공** — 사진 위에 글자를 얹지 않고, 제목과 정보는 사진 아래에. 사진이 없으면 나라별 그라데이션 커버
- **확인은 한 번만** — 삭제·초기화만 iOS 경고창으로 묻고, 나머지는 즉시 반영
